# Code of Conduct

## Our standard

This project welcomes contributors of all backgrounds. We expect everyone to
engage respectfully, technically, and in good faith.

**Encouraged:** clear, kind, constructive feedback; respecting differing
viewpoints; focusing on what is best for the project and its users.

**Not tolerated:** harassment, personal attacks, discriminatory language,
trolling, or publishing others' private information. Keep this project's
security focus lawful: do not use issues, PRs, or discussions to coordinate or
solicit unauthorized access to systems.

## Scope

Applies to all project spaces — issues, pull requests, discussions — and to
public spaces when representing the project.

## Enforcement

Maintainers may edit, remove, or reject contributions and comments that violate
this policy, and may block repeat offenders. Report concerns privately via the
repository's **Security** tab → “Report a vulnerability”, or to the maintainer.

This document is a short, project-specific code of conduct inspired by the
[Contributor Covenant](https://www.contributor-covenant.org/).
